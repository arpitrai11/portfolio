# Arpit Rai — Full Stack Software Engineer Portfolio

An engineer's workstation portfolio interface built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**. Features interactive blueprint architecture, AWS S3 project storage explorer, Raycast-inspired application launcher, system performance telemetry, and command palette.

---

## 🛠️ Featured Projects & Production Systems

### 1. JAL-DRISHTI
- **Category:** AI Flood Prediction & Early Warning Platform
- **Technologies:** Python, REST APIs, React, TypeScript, ERA5-Land Reanalysis
- **Overview:** Basin-scale flood intelligence and early-warning platform for Assam, India, combining historical flood events, ERA5-Land rainfall reanalysis, upstream rainfall, hydrological connectivity, and terrain data. Features historical event replay and district-level intelligence maps.
- **Repository:** [github.com/arpitrai11](https://github.com/arpitrai11)

### 2. AI-Generated Social Media Posting
- **Category:** AI & Workflow Automation
- **Technologies:** n8n, Gemini API, Kie.ai, Telegram Bot API, Docker
- **Overview:** Containerized n8n automation pipeline generating contextual captions, hashtags, and visual assets tailored to business profiles, featuring an interactive Telegram bot gate for one-click human approval before multi-channel publishing.
- **Repository:** [github.com/arpitrai11](https://github.com/arpitrai11)

### 3. Chhattisgarh Taxi Service
- **Category:** Full-Stack Production Ride Booking Platform
- **Technologies:** React, Node.js, Express.js, MongoDB, Tailwind CSS
- **Overview:** Full-stack production taxi booking portal with JWT authentication, real-time ride reservations, vehicle tier selection, driver allocation, and an administrative dispatch management dashboard synced with MongoDB Atlas.
- **Live Platform:** [chhattisgarhtaxiservice.com](https://chhattisgarhtaxiservice.com)

### 4. Responsify
- **Category:** Developer Tool & Multi-Viewport Chrome Extension
- **Technologies:** Manifest V3, React, TypeScript, Vite, Tailwind CSS, declarativeNetRequest
- **Overview:** Production-grade Chrome Extension for responsive design testing and multi-device viewport inspection. Features an infinite canvas workspace with synchronized scrolling across mobile/tablet/desktop frames, zero X-Frame-Options blocking via declarativeNetRequest, and an embedded DevTools inspector drawer.
- **Repository:** [github.com/arpitrai11/Responsify.git](https://github.com/arpitrai11/Responsify.git)

### 5. MeetMind AI
- **Category:** AI Chrome Extension & Meeting Intelligence
- **Technologies:** Manifest V3, React 18, TypeScript, Vite, Tailwind CSS, IndexedDB, Gemini 2.0 Flash, Groq Whisper
- **Overview:** Local-first, privacy-focused Chrome Extension capturing browser meetings (Google Meet, Teams, Zoom) using chrome.tabCapture and microphone mixing with zero-loss audio loopback. Features local storage in IndexedDB, free automated transcription with Whisper via Groq, and developer-specific task extraction (APIs, endpoints, frontend bugs, DB schemas, Jira/Linear task summaries) powered by Google Gemini 2.0 Flash.
- **Repository:** [github.com/arpitrai11/MeetMind](https://github.com/arpitrai11/MeetMind)
